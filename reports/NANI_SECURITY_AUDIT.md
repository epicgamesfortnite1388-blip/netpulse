# NANI Security Audit

## Local LLM boundary

- Disabled by default; requires explicit environment configuration.
- Spawns a fixed executable path with an argument vector; no shell, no user-controlled command.
- Prompt is generated by Rust from structured facts, never passed directly from the webview.
- Timeout kills the child; output is capped and validated.
- Model output is explanation-only. It cannot change diagnosis, select recovery actions, write files or execute commands.
- The deterministic explanation is always present and is the authoritative text.

## AI data flow

- No raw logs, packet payloads, credentials or configuration text enter the local model prompt.
- The prompt contains API ids, health states, failure categories, counts, reliability and drift counts.
- No cloud AI call exists in the desktop path.

## Application controls (unchanged, re-verified by build)

- Sidecar bound to loopback with bearer auth.
- CSP restricts scripts/connections.
- No secrets in the packaged backend or web bundle (scan returned no matches).
- Deterministic validation and authorization remain authoritative.

## Dependency audit

`npm audit --omit=dev --audit-level=high` exited 0 with 3 moderate advisories (`glob`, `minimatch`, `@fastify/static`). No high or critical findings. Not upgraded immediately before release because the lockfile change would invalidate the regression evidence.

## Artifacts

Build is unsigned; no certificate is present, and no signature was fabricated. Verify SHA-256.

## Residual risks

- A malicious local executable placed at the configured LLM path would run with the app's privileges; the path is user-controlled configuration, not remote input.
- Model output may still contain misleading prose; the UI labels it as an explanation and always shows deterministic facts.
- In-memory learning state is lost on exit; no data-at-rest concern, but no persistence either.

No critical or high-severity issue was found in the changed code.
