## UI DESIGN 2.0 — palette unification, contract hardening, 12 reports

Mission brief: "UI DESIGN MISSION 2.0" — elevate the existing implemented UI, not rewrite.
Delivered 12 reports `reports/UI_DESIGN_2_01..12_*.md`. Overall verdict: PASS WITH CONDITIONS
(blocking: C-04 wall-clock perf test, C-05 Phase 6 progressive disclosure not implemented).

### Palette unification (the big one)
110 raw Tailwind palette utilities across 11 files had **no light-theme counterpart**
(`identity.css` overrides `--color-*`, literals do not). Proof of severity:
`text-violet-200` (#ddd6fe) on a white card = **1.39:1**. WireGuard's glyph was `rose`
(the danger hue) and OpenVPN's `amber` (the warning hue) — native tunnels painted as faults.
- Mapped to 3 token families only: semantic (`ok/warn/danger/accent`), `--color-proto-*`,
  `--color-aether*`. Engine glyphs collapsed from 6 arbitrary hues to 1 (accent).
- Special case: `.aether-stage` is a hard-coded dark gradient in BOTH themes, so its ink
  must stay `text-white/*` — state tokens flip to dark values in light theme.
- Script: `scripts/oneoff/unify-palette.mjs` (one-off, already applied, do not extend).

### Contract: 47 → 55 assertions (`scripts/assert-ui-contract.mjs`)
New: no raw palette; no hard-coded colour values; light-theme block must declare every
semantic token; ok/warn/danger distinct in both themes; container-query + ConnectionHero
must not reintroduce `lg:grid-cols-[236px`; every route declares exactly one h1;
reduced motion covers `animate-*` family (spinners exempt).
- **NEW: `scripts/verify-contract-assertions.mjs`** — applies 9 mutations to the real CSS and
  requires each to be rejected (9/9). An assertion that never failed is unverified; this
  caught 2 genuinely broken assertions (regex escaping) plus 2 bad mutations of my own.
- `UI_CONTRACT_CSS=<path>` env var points the contract at a synthetic stylesheet.

### Harness bugs found (both were silently producing wrong evidence)
- `ui-capture.mjs` wrote `data-type-scale="1.25"`, but the ramp keys off NAMED steps
  (`large`=1.125, `xl`=1.25) — so 125% captures were silently 100%. Now maps number→name
  AND reads back the resolved `--type-scale`, aborting if it did not apply. Every manifest
  entry records `applied: {theme, typeScale, rootFont}`.
- `ui-probe.mjs` now reports computed `color`/`bg`/`border` so colour claims are numbers.

### Real defects fixed (24 total, see report 01 §4)
- Dashboard printed two contradictory verdicts ("Degraded Good") — two score scales; unified.
- `DNS —as` (em dash + `ms` at 12px read as a word).
- Connection panel collapsed at 1024px: viewport `lg:` breakpoint sizing a column → container queries.
- Copilot seeded a fake "I'm NetPulse Copilot" message styled like a model answer.
- `censorshipHint` DTO declared `{level, dpiInferred:false}` but API sends `{likely, ...}` —
  branch was unreachable, so good news rendered in warning amber.
- Live Map + Node Detail had no `h1` (EngineHero clamps to h2; added `pageTitle` prop).
- `bg-[#07121b]` / `bg-[#060a12]` never flipped in light theme.

### Gotchas (additions)
- `.aether-stage` is permanently dark — never put theme-flipping tokens on its text.
- `headingTag()` clamps to a minimum of `h2`; a page title must opt in via `EngineHero pageTitle`.
- `mapClusterPerf.test.ts` asserts wall-clock budgets (<100ms, <25ms) and fails under load.
  Suite is 56 files / 534 tests / 0 failures when idle (9/9 runs); load-sensitive.
- Vitest counts seen while Chromium captures ran concurrently were unreliable — verify idle.
